\# Сайт автора книг



Сайт для демонстрации книг одного автора.



\## Структура

\- Главная страница

\- Каталог всех книг

\- Страница каждой книги с описанием и отрывком

\- Информация об авторе

\- Контакты



\## Технологии

\- Python (FastAPI)

\- HTML/CSS/JavaScript

\- Vercel для хостинга



\## Как добавить книгу

Отредактируйте файл `data/books.py`, добавьте новую книгу в список BOOKS.
